# 토요일까지 가벼워지기 💗

결혼식 전 화~금 4일 동안 식단·운동·생활습관을 체크하는 개인용 모바일 웹앱(PWA)입니다.
서버 없이 동작하고, 기록은 휴대폰 브라우저(localStorage)에 저장됩니다.

---

## 1. 파일별 역할

| 파일 | 역할 |
|---|---|
| `index.html` | 화면의 뼈대. D-DAY, 실천율, 체크리스트, 기록 입력, 그래프, 설치 안내, 설정, 하단 요일 탭 |
| `style.css` | 디자인. 아이보리 배경, 민트·핑크 포인트, 둥근 카드, 큰 체크박스, 애니메이션 |
| `app.js` | 앱의 동작. 요일별 체크리스트 데이터, 체크·저장, 실천율 계산, 그래프, 토요일 화면, 초기화 |
| `manifest.json` | 홈 화면 설치 정보 (앱 이름, 아이콘, 색상) |
| `sw.js` | 서비스 워커. 파일을 휴대폰에 저장해 두어 인터넷 없이도 열리게 함 |
| `icons/` | 앱 아이콘 (안드로이드 192·512px, 아이폰 180px) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리도록 하는 빈 파일 (지우지 마세요) |

> 체크리스트 문구를 바꾸고 싶으면 `app.js` 위쪽의 `DAYS` 부분만 고치면 됩니다.

## 2. GitHub에 올리기 (웹 브라우저만 사용)

1. <https://github.com> 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
3. Repository name에 `saturday-light`처럼 영어 이름을 쓰고, **Public**을 선택한 뒤 **Create repository**를 누릅니다.
4. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 압축을 푼 `saturday-light` 폴더 **안의 파일과 icons 폴더를 모두** 끌어다 놓습니다.
   - `index.html`이 저장소의 맨 위(첫 화면)에 보여야 합니다. 폴더째 한 단계 더 들어가 있으면 안 됩니다.
   - `.nojekyll`처럼 점으로 시작하는 파일은 컴퓨터에서 숨겨져 보이지 않을 수 있습니다. 없어도 이 앱은 동작합니다.
6. 아래 **Commit changes**를 누릅니다.

## 3. GitHub Pages로 배포하기

1. 저장소 화면 위쪽 **Settings** → 왼쪽 메뉴 **Pages**로 갑니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 둡니다.
3. **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~3분 뒤 새로고침하면 위쪽에 주소가 나타납니다.
   예) `https://내아이디.github.io/saturday-light/`
5. 그 주소를 휴대폰으로 보내서 열어 봅니다. (카톡 '나에게 보내기'가 편해요)

> 주소가 404로 나오면 2~3분 더 기다린 뒤 다시 열어 보세요.

## 4. 휴대폰 홈 화면에 설치하기

**아이폰 (반드시 Safari)**
1. Safari로 주소를 엽니다. (카톡 안에서 열렸다면 오른쪽 아래 메뉴 → 'Safari로 열기')
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**를 누릅니다.
3. 이제부터는 **홈 화면 아이콘으로만** 여세요.
   아이폰은 Safari와 홈 화면 앱의 저장 공간이 서로 따로라, Safari에서 체크한 내용은 홈 화면 앱에 보이지 않습니다.

**안드로이드 (Chrome)**
1. Chrome으로 주소를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
   (앱 안의 '홈 화면에 설치하는 방법' 카드에 **지금 앱으로 설치하기** 버튼이 뜨면 그걸 눌러도 됩니다.)

## 5. 휴대폰에서 점검하기

설치 후 아래 순서대로 확인해 보세요.

- [ ] 상단에 D-4(화요일 기준)와 오늘 날짜·관리 1일차가 보인다
- [ ] 체크박스를 누르면 체크되고, 위쪽 원형 그래프와 요일 막대가 바로 바뀐다
- [ ] 체크한 항목을 다시 누르면 해제된다
- [ ] 그날 항목을 모두 체크하면 축하 메시지와 하트가 떨어지는 애니메이션이 나온다
- [ ] 하단 화·수·목·금 탭을 누르면 해당 요일 체크리스트와 기록으로 바뀐다
- [ ] 체중·허리둘레를 입력하면 아래 그래프에 점이 생긴다
- [ ] 앱을 완전히 닫았다가 다시 열어도 체크와 기록이 그대로 있다
- [ ] 비행기 모드에서 앱을 열어도 화면이 뜨고 체크가 된다
- [ ] '모든 기록 초기화'를 누르면 확인 창이 뜨고, '취소'하면 아무것도 지워지지 않는다
- [ ] 설정의 '토요일 화면 미리보기'로 결혼식 당일 화면을 미리 볼 수 있다 (토요일에는 자동으로 뜸)

> 결혼식 날짜는 처음 연 날 기준 '다가오는 토요일'로 자동 설정됩니다. 다르면 설정에서 바꾸세요.

## 6. 수정 후 다시 올릴 때

1. GitHub 저장소에서 고칠 파일을 눌러 연필 아이콘으로 수정하거나, 파일을 다시 업로드합니다.
2. `sw.js` 맨 위의 `saturday-light-v1`을 `v2`, `v3`…로 바꿔 함께 올립니다.
3. 휴대폰에서 앱을 껐다 켜면(필요하면 두 번) 새 버전이 적용됩니다. 기존 체크 기록은 유지됩니다.
